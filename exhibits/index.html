Exhibits.

A design experiment. I gave the same brief to three frontier models — GPT, Grok, and Fable — and asked each to build a single-page experience for this site using whatever the web could do in August 2026. Fable answered twice: once restrained, once told explicitly to go loud. Nothing here is a template, a framework, or a picked winner. Four files, one prompt.

The brief, verbatim "Push the boundaries of what's possible in web design with the absolute latest in CSS, WebGL, shaders, etc. as of August 2026 and create the most impressive, informational single-page experience you can imagine. Build it based on concepts associated with workbypk.com."

Everything below is a concept, not the site. All market-looking lines are synthetic. Read them the way you'd read a backtest: check what the code does, not what it says it does.

EXHIBIT 01

GPT — the cockpit →

Maximal terminal aesthetic. The only entry that actually ships WebGPU — a WGSL shader with WebGL2 and canvas fallbacks beneath it, and a label telling you which tier you landed on. Abandons the house palette entirely and argues its choices in a README.

webgpu → webgl2 → 2d · inter + space grotesk · cyan/violet on near-black · 85 KB

 EXHIBIT 02

Grok — the graph →

The minimalist. A quarter the size of the cockpit, the only one that kept Switzer, colors in oklch throughout. A sparse particle graph of systems forming and dissolving. Its docstring prefers a WebGPU path; the code renders WebGL through three.js.

webgl via three.js (vendored) · switzer · oklch · 22 KB + library

 EXHIBIT 03

Fable — take one, the essay →

Restraint as the position. An interactive essay in the house garnet and paper: a shader whose hero line is literally a sum of three cycles, an instrument with a phase readout, margin notes anchored beside the prose, and cycles you can hear as a chord.

webgl2 + web audio · switzer · garnet/paper/gold · 37 KB

 EXHIBIT 04

Fable — take two, one full cycle →

The same model told to go loud. The page itself is one cycle, trough to trough: a single phase variable drives the shader's energy, a revolving dial, a scrubbable regime map, and a drone that brightens at the crest — all on one shared clock.

webgl2 + web audio · clash display + switzer · night garnet/gold/ember · 34 KB

Notes on what the four builds agree on, where they diverge, and what their comments claim versus what their code does — coming in the build log.
